# SP Cricket Academy

A modern, responsive React.js application for SP Cricket Academy showcasing facilities, reviews, achievements, and more.

## Features

- **Sticky Header**: Logo and navigation that sticks to the top when scrolling
- **Hero Section**: Beautiful background image with overlay text
- **Facilities Grid**: Showcasing batting, bowling, fielding, and night sessions
- **Reviews Section**: Testimonials with background images
- **Achievements**: Grid layout displaying players selected to U19 and State teams
- **Responsive Footer**: Complete with contact information and links

## Technologies Used

- React.js
- Bootstrap 5
- CSS3
- HTML5

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.
